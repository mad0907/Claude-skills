# Sources (widely taught concepts)

*This toolkit references public standards, laws and widely taught concepts only. It names no companies, products or individuals.*

- **Portfolio matrices:** the growth-share matrix and the nine-box attractiveness-vs-strength matrix are standard strategy-curriculum tools for multi-business portfolios.
- **Economic profit and value-based management:** return on capital vs cost of capital as the test of value creation (corporate-finance curricula).
- **Parenting advantage and the best-owner test:** the corporate-strategy principle that a parent should own a business only if it adds more value than other potential owners.
- **Dynamic resource reallocation:** research evidence that companies which reallocate capital more actively across units tend to deliver higher shareholder returns.
- **Five Forces and VRIO:** inputs to the attractiveness and strength scores (see the related skills).
