# Sources (widely taught methods; verify current versions)

*This toolkit references public standards, laws and widely taught concepts only. It names no companies, products or individuals.*

- **Sensitivity, switching values and scenario analysis:** public appraisal guidance (e.g. UK HM Treasury *Green Book*: sensitivity analysis and switching values) and standard corporate-finance curricula.
- **Monte Carlo simulation:** standard decision-analysis practice; use correlated inputs and report percentile outcomes. See risk-analysis guidance in ISO 31010:2019 (risk assessment techniques).
- **Expert elicitation of ranges:** structured elicitation practices (e.g. asking for P10/P50/P90 with reasons; calibration training) reduce overconfidence.
- **Optimism bias:** documented tendencies in cost overruns and benefit shortfalls. Set ranges asymmetrically where history supports it.
