# Sources (widely taught concepts)

*This toolkit references public standards, laws and widely taught concepts only. It names no companies, products or individuals.*

- **Issue trees / logic trees and the MECE principle:** standard structured problem-solving techniques taught in business schools and consulting training.
- **Driver decomposition:** profit and return trees from management accounting.
- **Root-cause analysis:** cause-and-effect (fishbone) and "5 whys" from quality management.
- **Hypothesis-driven problem solving:** using trees to prioritise analysis (see the `hypothesis-tree` skill).
