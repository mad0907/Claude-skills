# Sources (widely taught concepts)

*This toolkit references public standards, laws and widely taught concepts only. It names no companies, products or individuals.*

- **Hypothesis-driven problem solving:** a standard approach in strategy consulting and business-school problem-solving courses (state an answer, define what must be true, test the critical claims first).
- **Falsification:** the scientific principle that hypotheses should be framed so that evidence can disprove them.
- **Cognitive biases:** confirmation bias, anchoring and motivated reasoning in decision-making; debiasing with pre-set criteria, devil's advocates and red teams.
- **"What would have to be true":** a strategy-practice technique for making assumptions explicit and testable.
- **Desirability, feasibility, viability:** a common lens from innovation and design practice.
