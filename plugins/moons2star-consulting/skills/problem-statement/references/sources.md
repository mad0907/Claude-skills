# Sources (widely taught concepts)

*This toolkit references public standards, laws and widely taught concepts only. It names no companies, products or individuals.*

- **Structured problem solving:** defining a specific, measurable, action-oriented problem statement before analysis is a core step taught in management-consulting and business-school problem-solving courses.
- **SMART criteria** (specific, measurable, achievable, relevant, time-bound) applied to problem and objective definition.
- **Root-cause thinking:** "5 whys" and cause-and-effect analysis from quality-management practice, used here to separate symptoms from causes.
- **Project chartering:** scope, out-of-scope and stakeholder definition as in professional project-management standards.
